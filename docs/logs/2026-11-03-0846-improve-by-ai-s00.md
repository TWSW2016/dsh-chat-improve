## 结果与证据

1. **`useInput` 选择器**：`export type SnapshotSelectorHook<T> = <S>(sel: (s: T) => S, eq?: (a: S, b: S) => boolean) => S`（`packages/client/store/src/contract.ts:20`）。可以直接 `useInput(s => s.draft)`，无需整快照 + memo。
2. **`setDraft` 行为**：
   - `SessionInputShell.setDraft(text)`：`resolveDraftInput(text)` 后，字符串入参的 `references` 为空 → 走 `draftEditor.setDraft(draft.text)`（`facade.ts:223-231`），**不会保留 @ 引用 chip**。
   - `DraftEditorRuntime.setDraft`：`$getRoot().clear()` + `$appendParagraphs(clean)`，`{ discrete: true, tag: HISTORY_MERGE_TAG }`（`editor/runtime.ts:199-206`）；注释明写 “the caret lands at the end”“merged into history so a seed is not an undoable step of its own”。
   - **没有 focus 调用**；`InputActions` 也没有 `focus` 成员（installed 契约 `.research/tar/package/lib/types/client/contract/input.d.ts:206-226`）。
3. **dock 槽能力**：`conversation.input.dock` 的 standardProps 含 `useInput`、`inputActions`、`sessionId`，另有 ownerProps `InputZone { session, input }`。现有 occupant：`todo`(0)、`goal`(10)、`queue`(20)。还原条可以自己完成写回，不需要跨组件桥。
4. **会话模型**：host `sessions` 有 `get(id: SessionId): Session | undefined`（“Look up a live session”）；`Session.requestHeader(): EpochHeader | undefined`，`EpochHeader.config: LlmCallConfig { provider, model }`。所以 `sessions.get(id)?.requestHeader()?.config` 即该会话最近一次请求的模型；空会话返回 `undefined` → 回退 `agentDefaultModel.currentSelection()`。
5. **`ctx.inject([...], cb)`** 是核心插件通用写法（`client/connection/src/index.ts:141` 等），Host 半可以用它在 webServer/connection 就绪后再注册路由。

## 决策

- 模型解析改用 `sessions.get(sessionId)`，**不**依赖 `agent.session`（Agent 的完整形状在 inspect 里被截断，没必要赌）。
- 还原条放到 `conversation.input.dock`（那里就有 `inputActions`），失败提示也在同一条里复用。
- 替换后手动 `document.querySelector('[data-composer-input]').focus()`：官方 API 没有 focus 座位，这一步写明原因，别让后来者以为是随手越界。
- 只使用 installed 0.2.1-rc.5 契约里存在的成员：不使用 repo（0.2.2-alpha.2）里新出现的 `insertQuote` / `persistDraft`。
