## 决策

- **不走 remove → install 的“重装”捷径**：`already-installed` 只说明版本相同；为了触发 Host 重载而先卸载用户正在使用的插件，中途失败会留下更差的状态。改用 `set_plugin` 关→开，同样重新 import Host 半，且每一步都有 `application` 回执。
- **不另起一个 `dsh web` 来拿 token**：那会是第二个服务实例，和用户当前 GUI 不是同一个进程，验证不到这条部署；而且运行说明明确不要自行起替代服务器。
- **验收表按事实分档**：注册/路由写成“通过”，交互写“待交互验收”，不把间接证据升格成“点通了”。
